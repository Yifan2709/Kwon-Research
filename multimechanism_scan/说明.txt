本目录只保留共享模型的兼容入口，参数只读自根目录 config/ 下的 atomic.json、experiment.json、numerics.json。详细说明见根目录 README.md。

coherence.py 和 coherence_scan.py 与 internal_dynamics 共用 kwon 中的同一份实现。
check_kwon.py 使用统一电压扫描，不再内置旧数据的极大/极小值位置。
scan.py 中可选现象学模型的参数全部需要明确填写，不再带入旧拟合常数。

本目录既有 CSV/PNG 是历史归档结果，没有按当前配置重算，也不会被新计算入口自动读取。

示例（从代码包根目录执行）：
python -m kwon.parameters --check
python multimechanism_scan/check_kwon.py --csv outputs/kwon_control.csv
python multimechanism_scan/scan.py --output-dir outputs
